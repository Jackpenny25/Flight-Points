## Environment Setup

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Edit `.env` and set your admin PIN:
   ```dotenv
   VITE_ADMIN_PIN=your-secure-pin-here
   ```

3. Never commit your `.env` file to git!
