# Reward Scheme Intro Notes

S1 Title: Intro to what it is, how it works, and signup.
S2 What: Digital points for effort, attendance, teamwork, and standards.
S3 Why: Fair recognition, consistency, motivation, and clear progress.
S4 Points: Awarded by authorized staff; point givers own flight; evidence-based.
S5 Rewards: Active, Claimed, Expired. Suggestions: Pending, Approved, Rejected.
S6 Signup: No self-signup; SNCO/admin creates username accounts and roles.
S7 Roles: Cadet view; staff/point giver award/manage; SNCO/admin oversee.
S8 Controls: Role auth, admin safeguards, revision history, integrity checks.
S9 Cadet actions: Attend, contribute, keep standards, join votes/suggestions.
S10 Example: Weeks 1-3 steady effort -> points growth -> reward eligibility.
S11 FAQ: Access via staff; only authorized roles award points.
S12 Close: Consistency wins; ask staff for access/help; Q&A.
